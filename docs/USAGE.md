# 托盘管家使用说明

## 开始使用

1. **解压整个 ZIP** 到可写目录；保留 `TrayLeaf.exe` 与 `TrayLeaf.exe.config` 在同一文件夹。
2. 双击 `TrayLeaf.exe`。正式版清单默认请求管理员权限；接受 Windows UAC 后启动。
3. 在“当前程序”勾选要关闭的应用，再点击“关闭所选程序”，或按 **Ctrl+Alt+1**。
4. 结束游戏后进入“恢复记录”，勾选要重新启动的项目，逐项选择“使用提权”，再点“开启所选程序”，或按 **Ctrl+Alt+2**。
5. 点击窗口关闭按钮只隐藏窗口，程序继续驻留托盘。双击托盘图标打开；右键菜单可打开、关闭、恢复、进入设置或退出。

**恢复仅发送启动请求，不恢复文档、登录会话、窗口位置或被结束前的内存状态。先保存工作！**

## 字体与 2K / 4K 显示

- “设置 → 外观与显示”可选择本机安装的字体，默认 **微软雅黑（Microsoft YaHei）**。
- 字体下方提供预览，点击页面底部“保存设置”后立即应用于 WPF 主界面、启动信息编辑窗口与程序选择窗口；重启后保留。
- “默认字体”将选择改回微软雅黑，仍需点击“保存设置”。保存的字体已卸载时回退至默认字体。支持本机物理字体及 WPF 内置复合字体，避免可选字体被静默替换。
- 字体目录仅首次打开设置页时枚举，列表使用虚拟化，不为每一项加载独立预览。
- 使用 WPF 逻辑尺寸、布局取整、像素对齐与 **Per-Monitor V2**，跟随 Windows 显示缩放。
- 请在 Windows“设置 → 系统 → 显示 → 缩放”中选择合适比例，不需要为了 2K / 4K 手动改程序分辨率。
- 可调整窗口大小；设置页可滚动，字体较大时请向下滚动到保存按钮。
- 检查覆盖 96/144/192/288 DPI 离屏渲染；**没有真实 2K/4K 多屏切换硬件实测**。

## 进程识别、选择与添加

- 默认模式为 **托盘 / 任务栏程序**：可见顶层窗口、传统通知区域、能确认的通知图标。
- 可切换“全部运行进程”。Windows 版本和第三方托盘实现不同，不能保证每个图标都能精确归属；漏项可切换全部模式、手动添加或定位窗口。
- 设置中的“补充显示托盘候选”依据系统历史图标记录匹配仍在运行的程序；候选不是当前可见图标的确证，默认关闭且不自动勾选。
- 同一完整 EXE 路径归为一组，关闭时处理该路径的现有实例，包括同路径后台进程；**不递归终止不同 EXE 的子进程**。界面工作集之和不等于保证可释放的物理内存。
- “＋ 添加”可浏览选择 EXE。“◎ 定位窗口”会暂时隐藏本工具，鼠标左键点击目标窗口后识别进程名称、PID 与路径；Esc 或 30 秒超时取消。新添加项需检查后手动勾选。
- 桌面、宿主窗口、多进程应用、系统保护进程可能定位到宿主或无法读取路径；请检查“启动信息”，不要假设窗口标题就是 EXE。
- 勾选、权限、自定义项和已移除程序保存在数据库中。

## 移除程序与恢复显示

- 点击“当前程序”底部的 **移除程序**，在独立窗口中勾选不想显示的项目，再点 **移除所选**。支持搜索与全选当前结果；这里的选择与一键关闭的勾选相互独立。可移除自动识别项和手动添加项。
- 移除后立即从当前列表隐藏，并取消其关闭勾选；刷新、切换识别模式和重启后继续生效。**移除不会关闭或卸载程序**，已有恢复记录、启动参数和提权选择继续保留。
- 在 **设置 → 已移除的程序 → 管理已移除程序** 中选择项目并恢复显示。解除排除后，程序会在下次符合识别条件时重新出现；不会自动启动，也不会自动勾选关闭。
- 已知 EXE 路径按完整路径忽略大小写排除；暂时读不到路径时按进程名称排除。再次通过“添加”或“定位窗口”明确加入该程序，也会解除对应排除。
- 下拉菜单、选中行、复选框及移除窗口采用一致的浅蓝白色样式；页面标题末尾不加句号。

## 关闭与恢复的边界

- 执行关闭前将名称、完整路径、启动参数、权限和批次写入 SQLite。无法保存有效可恢复路径时拒绝该批次关闭。
- 先请求正常关闭并等待约 5 秒；仍在运行的项目逐项询问是否强制关闭。取消强制关闭时，可能已有部分同路径实例正常退出。
- 通过 PID、启动时间和路径核对进程身份，避免把复用 PID 的其他程序结束。
- 风险分类包括 Windows 关键标志、系统基础/安全进程、`svchost.exe` 与承载 Windows 服务的进程。默认弹窗警告，用户可确认继续；设置可关闭这类提醒。
- **关闭提醒不代表安全、不等于关闭所有确认，更不能绕过 Windows 的保护。** 工具自身、保留 PID 和系统拒绝访问的进程仍无法结束。误关系统组件可能黑屏、注销、服务中断或蓝屏，不建议尝试。
- 恢复参数来自 WMI 命令行快照；读取受限时可在“启动信息”手动补充，不保证所有程序都能读取。每组保存一份启动信息，不重建多个实例各自的参数。
- 恢复前检查同路径程序是否已经运行，已运行则跳过；每组最多发送一次启动请求。
- 勾选“使用提权”通过 UAC 启动；未勾选时，从管理员主程序经桌面 Explorer Shell 发送普通权限启动请求，不静默回退为管理员。非标准 Shell 或桌面 Explorer 不可用时可能失败。
- 承载服务的 EXE 可被标记风险，但“恢复”不是服务管理器操作，不会代替 SCM 重启 Windows 服务。商店应用、受保护程序、自带特殊启动器的应用也可能无法按普通 EXE 恢复。
- “已发送启动请求”只代表系统接受请求，不保证应用持续运行。失败项可重试；中断/超时记录标“需核查”，避免自动重复启动。
- 普通历史保留最近 20 批；仍有待恢复或中断未决项的批次不自动裁剪。

## 自定义快捷键

进入“设置 → 全局快捷键”，在输入框按组合键，点击“保存设置”。
至少含 Ctrl、Alt 或 Win；Delete / Backspace 清除该动作的快捷键。

默认 Ctrl+Alt+1 关闭，Ctrl+Alt+2 恢复。两个输入框可以设置为同一组合键：有待恢复项时执行恢复，没有时执行关闭。
恢复快捷键处理最近一个含待恢复项的批次，并遵循该批次的恢复勾选。要跳过某项，请先到“恢复记录”取消勾选。
如果组合键被其他程序占用，会提示注册失败并尝试保留原快捷键。

## 数据与隐私

默认数据库：`%LOCALAPPDATA%\TrayLeaf\trayleaf.db`。
支持指定独立数据库：`TrayLeaf.exe --db "D:\TrayLeafData\trayleaf.db"`。
SQLite 使用 WAL；备份请先从托盘退出，再复制数据库。运行中备份需同时考虑 `-wal` / `-shm`。

数据库含路径和原始启动参数，参数可能含账号、令牌或其他敏感值。**本版不加密数据库**，不联网上传进程列表；请不要随意分享数据库或截图中的参数。EXE 故障日志位于 `%LOCALAPPDATA%\TrayLeaf\last-error.txt`。

## 系统要求与体积/资源

- 目标：Windows 10/11 **x64**，已启用 .NET Framework **4.8 或更高的 4.x 就地版本**，系统提供 `winsqlite3.dll`。
- 已在本机 Windows 11 x64 / .NET 4.x Release 534296 环境构建、测试；未在所有 Win10 版本实机验证。
- 无安装器；不注册开机自启。若自行设为开机启动，管理员权限请求仍受 UAC 限制。
- EXE 未做代码签名，Windows/SmartScreen 可能提示未知发布者；不要为此关闭系统安全防护，请审阅源码后决定是否运行。
- 不持续扫描、不自动清理内存、不修改系统服务配置，不使用“强行压低工作集”的伪优化。
