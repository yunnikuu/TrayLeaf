# 托盘管家使用说明

## 开始使用

1. **安装版**：双击 `Windows-x64-Setup.msi`，按中文向导完成安装；或选择**便携版**，完整解压 ZIP 到目录
2. 双击 `TrayLeaf.exe`。正式版清单默认请求管理员权限
3. 在“当前程序”勾选要关闭的应用，再点击“关闭所选程序”，或按绑定的快捷键 默认为 Ctrl+Alt+1
4. 结束后可进入“恢复记录” 勾选要重新启动的项目，按需求选择“管理员启动” 再点“开启所选程序” 或按绑定的快捷键 默认为 Ctrl+Alt+2
5. 窗口关闭只隐藏窗口，程序继续驻留托盘。双击托盘图标打开；右键菜单可打开、关闭、恢复、进入设置或退出

**恢复仅发送启动请求，不恢复文档、登录会话、窗口位置或被结束前的内存状态。先保存工作！**

## 字体设置

- “外观与显示” 可选择本机安装的字体，默认 **微软雅黑（Microsoft YaHei）** 字体下方提供预览 更改后需要点击保存应用
- 可调整窗口大小；设置页可滚动，字体较大时请向下滚动到保存按钮

## 进程识别 选择与添加

- 默认模式为 **托盘 / 任务栏程序**：可见顶层窗口、传统通知区域、能确认的通知图标。
- 可切换“全部运行进程” 不能保证每个图标都能精确归属；漏项可切换全部模式、手动添加或定位窗口
- “＋ 添加”可浏览选择 EXE。“◎ 定位窗口”会暂时隐藏本工具，鼠标左键点击目标窗口后识别进程名称、PID 与路径；Esc 或 30 秒超时取消 新添加项需检查后手动勾选
- 桌面、多进程应用、系统保护进程可能定位到或无法读取路径
- 勾选、权限、自定义项和已移除程序保存在数据库中

## 移除程序与恢复显示

- 点击“当前程序”底部的 **移除程序**，在独立窗口中勾选不想显示的项目，再点 **移除所选**
- 移除后立即从当前列表隐藏，并取消其关闭勾选；刷新、切换识别模式和重启后继续生效 **移除不会关闭或卸载程序**
- 在 **设置 → 已移除的程序 → 管理已移除程序** 中选择项目并恢复显示。解除排除后，程序会在下次符合识别条件时重新出现

## 关闭与恢复的边界

- 执行关闭前将名称、完整路径、启动参数、权限和批次写入 SQLite。无法保存有效可恢复路径时拒绝该批次关闭
- 批量关闭前统一确认：先向选中进程的顶层窗口（含隐藏窗口）请求退出，最多等待约 2.5 秒；普通程序仍未退出时自动结束。没有窗口的普通后台进程直接结束。风险进程在强制结束前仍单独确认；取消时可能已有部分同路径实例退出。请先保存未保存的数据
- 风险分类包括 Windows 关键标志、系统基础/安全进程、`svchost.exe` 与承载 Windows 服务的进程。默认弹窗警告，用户可确认继续；设置可关闭这类提醒
- **关闭提醒不代表安全、不等于关闭所有确认，更不能绕过 Windows 的保护**
- 工具自身、保留 PID 和系统拒绝访问的进程仍无法结束。误关系统组件可能黑屏、注销、服务中断或蓝屏，不建议尝试

## 自定义快捷键

进入“设置 → 全局快捷键”，在输入框按组合键，点击“保存设置”
至少含 Ctrl、Alt 或 Win；Delete / Backspace 清除该动作的快捷键

默认 Ctrl+Alt+1 关闭，Ctrl+Alt+2 恢复。两个输入框可以设置为同一组合键：有待恢复项时执行恢复，没有时执行关闭

## 数据与隐私

默认数据库：`%LOCALAPPDATA%\TrayLeaf\trayleaf.db`。
支持指定独立数据库：`TrayLeaf.exe --db "D:\TrayLeafData\trayleaf.db"`。

数据库含路径和原始启动参数，参数可能含账号、令牌或其他敏感值。**本版不加密数据库**，不联网上传进程列表；请不要随意分享数据库或截图中的参数
EXE 故障日志位于 `%LOCALAPPDATA%\TrayLeaf\last-error.txt`。

## 系统要求与体积/资源

- 目标：Windows 10/11 **x64**，已启用 .NET Framework **4.8 或更高的 4.x 版本**，系统提供 `winsqlite3.dll`
- 已在本机 Windows 11 x64 / .NET 4.x Release 534296 环境构建、测试；未在所有 Win10 版本实机验证
- 无安装器；不注册开机自启。若自行设为开机启动，管理员权限请求仍受 UAC 限制

## 安装版、修复与卸载（v0.2.1）

- 安装器会检查前置条件，但不联网下载运行库
- 中文向导允许选择安装位置；默认 `%LOCALAPPDATA%\Programs\TrayLeaf`。只为当前用户安装，不增加服务或开机自启动（计划后续版本加入）
- 安装完成不自动运行。以后从快捷方式启动时，EXE 仍按原设计请求管理员权限
- 卸载前请先从程序托盘菜单退出，不要在程序仍运行时强制移除
- 卸载只移除已安装文件、快捷方式与安装器注册信息，不删除 `%LOCALAPPDATA%\TrayLeaf\trayleaf.db` 再安装后可继续使用原设置和恢复记录
- 同一版本更换安装包内容时，先卸载旧安装版再安装；不要在已安装目录手工覆盖或直接移动文件
