# 轻羽归栈 TrayLeaf 使用说明

更新日期：2026-11-18

轻羽归栈可以临时关闭不需要的后台应用，释放资源，之后再按记录重新启动。玩游戏或特定场景时，可以用它整理后台，释放内存占用。

> **恢复只会重新启动程序，不会还原未保存的文件、窗口、登录状态或原来的工作会话。关闭前请先保存工作。**

## 1. 安装与第一次使用

- 支持 Windows 10/11 x64，需要 .NET Framework 4.8 或更高的 4.x 就地版本。
- **安装版**：运行 MSI，选择安装位置以及是否创建快捷方式、开启自启动。支持覆盖升级与同版本重新安装
- **便携版**：解压整个 ZIP 后运行 `TrayLeaf.exe`
- 软件默认申请管理员权限，可在“设置 → 设置 → 启动设置”调整。即使有管理员权限，也不保证所有程序都能关闭或启动

**快速上手**：打开软件 → 在“当前程序”勾选暂时不用的应用 → 点击“关闭所选程序” → 用完后进入“恢复列表” → 勾选需要重新打开的应用 → 点击“开启所选程序”

## 2. 当前程序

- **识别范围**：默认显示“托盘 / 任务栏程序”。找不到目标时，切换到“全部运行进程”，再点击“刷新”
- **搜索**：输入程序名称、进程名或路径筛选列表；勾选的程序会置顶
- **添加**：选择程序文件，加入自定义管理。添加操作本身不会启动或关闭程序
- **定位窗口**：点击后，再单击目标窗口；按 `Esc` 取消。如果目标已在识别列表中，软件会提示并定位到它，不会重复添加
- **启动信息**：先选中需要查看的程序，再查看路径、编辑启动参数等。参数中有空格或引号时，请保留原来的格式
- **关闭**：勾选程序后点击“关闭所选程序”。页面会显示进度、结果，以及未能关闭的程序名称；完成后显示关闭结果
- **恢复默认**：清除勾选，恢复默认排序，同时取消本次读取配置或历史后产生的置顶效果

**注意**：列表按程序路径合并，同一路径下的多个进程实例可能一起关闭。“全部运行进程”中包含不能随意关闭的进程，请逐项确认

## 3. 恢复列表

1. 选择对应的历史批次，或读取恢复配置。（默认会显示本次/上次关闭的程序）
2. 勾选需要启动的程序，在“管理员启动”列决定是否以管理员身份打开
3. 需要调整参数时，右键该项选择“编辑启动参数”，或使用“启动信息”
4. 点击 “开启所选程序” 进行恢复，查看页面上的恢复进度和记录状态

- 编辑后的参数会保存，供后续恢复使用，首次使用时会提示
- 记录状态先显示“成功发送请求”，随后会检查是否成功启动
- “启动成功”表示检测到了对应路径的进程，不代表程序已经登录或完成全部初始化。**通过文件关联打开等情况，可能只能确认请求已发送**
- 已运行的程序通常不能重复勾选。如果程序已经退出，列表状态却没更新，点击“刷新状态”后重试；“刷新记录”则用于重新读取历史
- 恢复操作结束后，软件会自动刷新一次“当前程序”列表

**恢复失败时**，先检查程序是否已移动或卸载、启动参数是否正确、权限是否为管理员模式。部分程序会交给其他进程继续启动，可以先看看实际窗口是否已打开，再决定是否重试

## 4. 历史记录与配置

- **历史记录**：关闭程序时，会保存路径、名称、启动参数和相关选项。关闭历史和恢复批次各保留最近 **10 条记录**，超出的旧记录会自动清理
- **保存配置**：勾选程序后点击“保存配置”，输入名称并确认，即可保存当前选择。关闭配置和恢复配置各最多添加 **5 个**
- **读取配置**：点击下拉框中的配置条目即可应用
- **编辑配置**：选择配置后点击“编辑”，可修改名称、条目、勾选状态和启动参数等。编辑页也可以添加程序
- **删除配置**：点击“删除”并确认，只会删除配置，不会影响其余功能
- 需要长期保留某次选择时，可以先读取历史、调整勾选，再保存为配置，避免记录超出历史数量上限后被清理

**配置关联**：在“设置 → 设置 → 软件设置”开启“关联配置”后，新增关闭配置时会建立对应的恢复配置。在“设置 → 配置管理”中，可以更改对应关系或选择“不关联”。使用关闭配置完成关闭后，进入恢复列表便会读取对应的恢复配置

## 5. 关联启动：关闭 A，恢复时启动 B

关联启动用来更换恢复时要打开的程序，**并不是 A 一启动就跟着启动 B**。

1. 打开“关联启动”，点击“添加关联程序”
2. 在列表中搜索、刷新或切换识别范围，也可以用“定位窗口”找到原程序 A，双击选择该程序
3. 点击“选择关联启动的程序”，在系统文件选择窗口中选中目标 B
4. 核对左右两侧的程序，编辑 B 的参数和管理员权限；双击目标名称可以自定义显示名称
5. 点击“确认关联”。新规则默认启用；尚未确认时，关闭相关小窗口即可取消选择

规则生效后，通过本程序关闭 A 程序，再恢复时就会开启对应的 B 程序。可以随时切换“规则状态”，也可以右键编辑或删除规则

**注意**：只要有启用的关联规则，“关联配置”就会自动开启，此时不能手动关闭该开关。文件选择窗口允许选择所有格式，但并非所有文件都能直接启动；请选择可执行程序，或已配置打开方式的文件

## 6. 隐藏、名称与程序路径

- **隐藏程序**：在“当前程序”勾选后点击“隐藏程序”，或右键隐藏单项。隐藏只是不再显示在管理列表中，不会关闭、删除或卸载程序
- **恢复显示**：进入“设置 → 程序管理 → 管理已隐藏程序”。恢复显示隐藏的程序
- **移除自定义程序**：在“管理自定义程序”中移除手动添加的记录。部分特殊程序仍可能出现在列表里；请使用“隐藏”
- **自定义名称**：右键选择“自定义进程名称”。改变软件内程序名称的显示；需要还原时，进入“管理自定义程序名称” 恢复原名称
- **查看位置**：右键 →“程序路径”→“打开程序路径”或“复制路径”

## 7. 快捷键与启动设置

- 默认关闭快捷键为 `Ctrl + Alt + 1`，默认恢复快捷键为 `Ctrl + Alt + 2`。
- 在“设置 → 快捷键”点击输入框录制组合键；两项设成同一组合键时，软件会根据待恢复状态切换关闭 / 恢复动作；**建议分开设置快捷键**
- **开机自启动**：登录 Windows 后启动轻羽归栈。
- **以管理员身份启动**：控制程序自身的启动权限，下次启动生效
- **静默启动**：仅在开启开机自启动、且软件由自启动启动时隐藏主窗口

**注意**：“静默启动”只作用于本程序，不代表被恢复的应用也会隐藏窗口。全局快捷键发生冲突时，请换用其他组合键

## 8. 设置

**软件设置**

- 可以分别开关程序关闭、强制关闭、隐藏程序等确认弹窗。如果之前勾选“不再提示”，也能在这里重新开启
- “补充显示托盘程序”会利用 Windows 保存的托盘记录，补充仍在运行、但未能确认为托盘的程序。这些候选程序当前不一定存在托盘图标
- 普通设置修改后会自动生效并保存

**数据**

- 在“设置 → 数据”查看、打开或更改数据目录
- 更改目录会迁移数据，并保留原数据库
- **启动参数可能含账号、令牌或其他敏感内容，不要随意公开数据库或配置内容。**

## 9. 重要注意事项

- **关闭前保存工作**，重点留意文档、下载、同步与正在执行的任务
- 关闭系统、服务等关键进程时会有风险提醒。确认继续可能造成**服务中断、黑屏、注销或系统崩溃**
- **已识别的杀毒类软件不能勾选关闭**
